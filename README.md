## About the Project

This project is a desktop music player application developed using Java. It provides a simple and user-friendly interface that allows users to manage their music library by adding, deleting, updating, and viewing songs. The project was created to improve my Java desktop application development skills and to apply object-oriented programming (OOP) principles.

## Features

- Add songs
- Delete songs
- View songs
- Update song information
- User-friendly interface

## Technologies Used

- Java
- Java Swing
- NetBeans IDE
- Git & GitHub

## What I Learned

- Desktop application development with Java
- Designing graphical user interfaces using Java Swing
- Applying Object-Oriented Programming (OOP) principles
